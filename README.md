## Features

- 🔍 Disease Search
- ⚖️ Disease Comparison
- 📊 Interactive Dashboard
- 📈 Analytics
- 📚 Medical Database Coverage
- 📋 Dataset Preview
- 📥 CSV Download

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
- NumPy

## Dataset

Orphanet Rare Disease Dataset

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
